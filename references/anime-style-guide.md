# 动漫风讲解图视觉与 Prompt 规范

本文件是「PPT 转动漫风讲解图」的视觉基准与生成模板。SKILL.md 负责流程，本文件负责画面怎么画、Prompt 怎么写。

## 1. 统一视觉家族

- **画风**：清新日系动漫插画 / 手绘动画分镜质感，线条圆润可爱，色块平涂为主，轻阴影不做写实投影。
- **固定角色**：同一套圆头小助手机器人（白色圆润机身、深色面部屏幕、圆形耳状构件）贯穿同一页的所有区块；需要人物时配简洁卡通学习者形象，不出现写实照片。
- **背景**：与原页气质一致的柔和浅色渐变（浅蓝紫、暖米白等），留出干净文字区；不堆装饰、不发光、不玻璃拟态。
- **配色**：整页不超过一个主色 + 一个强调色 + 中性灰。主色从原 PPT 取；强调色只用于当前阶段/重点条目高亮，不每块换色。
- **字体气质**：标题圆润醒目、字重足；正文清晰可读；图内文字用简体中文，标点用全角。

## 2. 版式到画面的映射

先识别原 PPT 的结构，再决定画面布局，结构关系必须保留：

| 原版式 | 画面处理 |
|---|---|
| 左右双栏 | 左右两个圆角场景，各配一个角色动作；左栏多为前提/判断，右栏多为清单/原则 |
| 三栏并列 | 三个等宽卡片，大小一致、顶部对齐，每栏一个小场景 + 一句注解 |
| 时间轴 / 阶段演进 | 沿上升或横向时间轴排列同一角色的多个成长阶段，节点逐级升高/变能干 |
| 左右对比 | 两个对照场景，只改变一个条件（如「只答题」vs「能干活」），用颜色/姿态区分 |
| 流程步骤 | 按顺序排列编号步骤，箭头或脚印连接，每步只改变一处 |

## 3. 把抽象概念变成看得见的类比

- 每个阶段/原则配一个可识别的小动作或物件：揽活、递任务清单、并肩赶路、抱成品、翻书查证、操作电脑等。
- 拟人标签要通俗（如「力气型选手」「喇叭型选手」「搭班子选手」），标签贴在对应角色旁。
- 类比只帮助理解，不替代事实；原页的阶段名、数字、术语、边界条件必须原样保留。

## 4. 文案保留与改写原则

- **锁定不改**：原页标题、时代/阶段名、编号、数字、专有名词、引用要点。
- **可口语化**：说明句改成短而直白的白话，但不改变原意，不新增结论、数据或案例。
- **不编造**：原页没有的统计数字、来源、案例不要补；信息缺失时保留原表述或标注待补。
- 每页保留原页的底部结论/趋势句；若原页有页脚来源或编号，一并保留。

## 5. 生成参数默认值

- 比例：横版 PPT 默认 16:9，`width=1920 height=1080`；原页为竖版或方形时跟随原图比例。
- 工具：有原图作为视觉锚点时用 `image_edit`，原图放入参考图列表；只凭文字构思新图时用 `image_gen`。
- 参考图职责：在 Prompt 中写清「图 1 提供版式结构与事实内容」「图 1 提供画风与角色参考」，不把参考图的品牌标识、人物身份照抄进新图。

## 6. Prompt 骨架

按以下顺序组织一段连续自然语言 Prompt，不拆成列表：

1. 参考图编号 + 承担的职责（版式 / 画风 / 角色）。
2. 整体画风、背景、配色、线条气质。
3. 顶部标题与副标题（文字用中文引号「」逐字写出）。
4. 逐区块描述：位置、角色动作、对话气泡或标签、对应文案。
5. 底部结论句。
6. 收尾约束：中文清晰准确、层级分明、无乱码伪文字、无 emoji、无多余文字。

示例骨架：

```text
参考图1的<横版/左右双栏/三栏/时间轴>信息结构，把整页重绘成清新日系动漫插画风格的科普讲解页，<背景与配色>，线条圆润可爱，用同一个圆头小助手角色贯穿各区块，浅显易懂。顶部主标题「<标题>」，副标题「<副标题>」。<按区块依次写：小标题、角色动作、气泡文字、注解>。页面底部「<结论句>」。所有中文文字清晰准确、层级分明，不出现乱码、伪文字、emoji 或多余文字。
```

## 7. 禁止项

- 不把原 PPT 的文字整段堆进图里；每区块留一句核心白话，细节交给交付时的文字讲解。
- 不在图内生成水印、Logo 占位、二维码或无法辨认的伪文字。
- 不使用高饱和撞色、彩虹色、发光边框；不把角色画成写实人物。
- 同一页内不混用两种以上画风；角色造型、线宽、色块语言保持一致。
