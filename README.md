# ppt-to-anime-explainer

把一页 PPT / 幻灯片（截图或文字）转成**清新动漫风、浅显易懂的讲解插画**的 Agent 技能（Skill）。结构和事实沿用原页，表达换成看得见的场景与角色动作，让没有背景的人也能一眼看懂。

## 适用场景

当你上传 PPT、课件、幻灯片截图，或提出下面这类需求时触发：

- 把某页转动漫风 / 卡通化 / 漫画风 / 示意图化
- 把偏抽象的商务、技术、方法论、趋势演进页面画成好懂的科普图
- 需要在出图之外，配一段分块的大白话讲解

## 工作流

1. **读取输入**：识别标题、副标题、各区块要点、结论、页脚与编号，同时读出版式关系。
2. **提炼事实清单**：锁定不可改动的标题、阶段名、编号、数字、术语、结论；其余说明句可口语化，不改变原意。
3. **判断版式**：左右双栏 / 三栏并列 / 时间轴 / 左右对比 / 流程步骤，画面保持原结构。
4. **设计动漫化方案**：统一角色与每个区块的小动作、物件；为抽象概念配通俗类比；确定主色与一个强调色。
5. **准备参考图**：本地附件先上传取得可引用 URL，以原图为参考锚定版式与事实。
6. **生成图片**：横版默认 16:9，按 Prompt 骨架逐区块描述，约束中文清晰、无乱码、无 emoji。
7. **交付讲解**：图片以卡片交付，并附一段按区块顺序的通俗讲解，保留原页结论。

## 安装使用

1. 克隆或下载本仓库。
2. 将整个 `ppt-to-anime-explainer/` 目录放到技能目录下：
   - 用户级：`.doubao/agent_mode/workspace/.user_skills/`
   - 内置级：`.doubao/agent_mode/workspace/.skills/`
3. 在对话中上传 PPT 截图并要求「转动漫风、讲明白」即可触发。

## 变体支持

- **拆多张独立图**：并列区块分别生成独立漫画图，沿用同一角色与配色。
- **学生 / 通俗版**：行业术语换成校园或日常例子，事实结论不变。
- **趣味类比版**：在克制商务版之外另做拟人化类比，两版并存。

## 事实边界

- 不编造原页没有的数字、案例、来源；信息缺失时保留原表述或标注待补。
- 不把品牌标识、真实人物身份照抄进新图。
- 图内文字以清晰可读为准，细节放到交付讲解里。
